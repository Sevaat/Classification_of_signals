# Классификация аномалий трёхфазных сигналов

Полный пайплайн машинного обучения для классификации аномалий в трёхфазных электрических сигналах (напряжение/ток) с использованием вейвлет-анализа и нескольких моделей классификации.

## 📌 Обзор

Данный проект реализует сквозной пайплайн для обнаружения и классификации аномалий в трёхфазных сигналах. Генератор создаёт реалистичные сигналы с различными типами аномалий, затем извлекаются признаки с помощью вейвлет-преобразования, и обученные модели классифицируют тип аномалии.

### Типы аномалий:

| Класс | Описание |
|-------|----------|
| `normal` | Нормальный сигнал с естественными вариациями |
| `sag` | Провал напряжения (кратковременное понижение) |
| `swell` | Перенапряжение (кратковременное повышение) |
| `interruption` | Прерывание (сильное ослабление одной фазы) |
| `unbalance` | Несимметрия фаз |
| `harmonics` | Гармонические искажения |
| `transient` | Переходный процесс (импульсное возмущение) |
| `flicker` | Фликер (модуляция амплитуды) |

## 🧠 Методология

### 1. Генератор сигналов
- Частота дискретизации: **2000 Гц**
- Длительность: **0.5 с**
- Базовая частота: **50 Гц**
- Реалистичный уровень шума: случайный в диапазоне `[0.03, 0.15]`

### 2. Извлечение признаков
- **Вейвлет-разложение** (`db4`, уровень 5)
- **Статистические признаки**: среднее, std, RMS, пик, асимметрия, эксцесс
- **Энергетические признаки**: энергия по уровням, отношения энергий
- **Энтропийные признаки**: энтропия коэффициентов, вейвлет-энтропия
- **Межфазные признаки**: дисбаланс RMS, корреляции между фазами

**Итого**: 135 признаков после удаления константных.

### 3. Модели
Сравниваются 4 модели классификации:

| Модель | Accuracy | F1-macro |
|--------|----------|----------|
| **SVM** (RBF) | **0.834** | **0.834** |
| XGBoost | 0.830 | 0.829 |
| MLP | 0.826 | 0.825 |
| Random Forest | 0.824 | 0.823 |

**Лучшая модель**: **SVM** с ядром RBF.

### 4. Устойчивость к шуму
Модель SVM протестирована на различных уровнях шума:

| Уровень шума | Accuracy |
|--------------|----------|
| 0.01 | 0.794 |
| 0.02 | 0.873 |
| 0.05 | 0.868 |
| 0.10 | 0.820 |
| 0.20 | 0.250 |

> Модель устойчива до уровня шума ~0.1, после чего качество резко падает.

### Топ-5 важнейших признаков

1. `rms_unbalance` — дисбаланс среднеквадратичных значений фаз
2. `a_detail_max_4` — максимум коэффициентов детализации (фаза A, уровень 4)
3. `avg_energy_detail_1` — средняя энергия детализации (уровень 1)
4. `rms_max_diff` — максимальная разница RMS между фазами
5. `a_detail_entropy_4` — энтропия коэффициентов детализации (фаза A, уровень 4)

## 📝 Примечания

- Датасет генерируется синтетически, поэтому результаты могут варьироваться при разных запусках.
- Для повышения точности рекомендуется увеличить количество сэмплов или добавить аугментацию данных.
- Модель SVM показывает лучшие результаты, но может быть заменена на ансамбль для повышения робастности.
